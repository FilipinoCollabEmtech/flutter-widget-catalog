1. Overview

SeeRuta is an offline vector map application built with Flutter, designed to display detailed geographic information for Cebu City using locally stored MBTiles vector data. The application follows a modular architecture that separates concerns between the UI layer, map rendering engine, data access layer, and business logic. The system is designed to operate fully offline after initial asset deployment, making it suitable for environments with limited or no network connectivity.

4. Design Decisions

• MapLibre GL over flutter_map: Migrated from flutter_map to MapLibre GL for native GPU-accelerated vector tile rendering, providing smoother zooming and panning performance.
• Offline-first architecture: All map data (MBTiles) and glyphs are copied to app storage on first launch, enabling fully offline operation without network dependency.
• Layer-based visibility: Admin-controlled layer visibility via MapLibre's setLayerVisibility() API, allowing dynamic show/hide of vector tiles, boundary mask, user location, and direction arrow.
• Style separation: Map styling is defined separately in cebu_style.dart and regenerated on each launch via offline_map_assets.dart, allowing style changes without app reinstall.
• ValueNotifier pattern: Reactive UI state management using ValueNotifier and ValueListenableBuilder for layer toggles, telemetry, and style rebuild triggers.

5. Data Flow

1. App launch: HomePage._prepareMap() calls OfflineMapAssets.prepare(), which copies MBTiles and glyphs to app storage and generates style.json.
2. Map rendering: CebuMapView initializes MapLibre with the style, adds boundary mask and user location layers.
3. User interaction: Admin toggles in AdminPage update ValueNotifiers, which CebuMapView listens to and calls setLayerVisibility() accordingly.
4. Style rebuild: Admin "Rebuild map style" bumps a ValueNotifier in main.dart, triggering HomePage to re-call prepare().
