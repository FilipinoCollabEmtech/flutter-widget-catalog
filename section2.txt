3. Build Workflows

• flutter.yml (triggers on push/PR to main): Builds and releases production APK from the main branch. This is the primary build workflow.
• flutter_beta.yml (triggers on push/PR to map_on_home): Builds and publishes beta releases tagged build-beta-<sha>.
• flutter_beta_gpu.yml (map_on_home only): GPU-accelerated build variant.
• build-mbtiles.yml (manual workflow_dispatch): Manual trigger for MBTiles-related builds.

4. Signing Configuration

• Application ID: org.research.seeruta
• App Label: SeeRuta
• Keystore: Fixed release key stored in GitHub Actions secrets
  - ANDROID_KEYSTORE_BASE64
  - ANDROID_KEYSTORE_PASSWORD
  - ANDROID_KEY_ALIAS
  - ANDROID_KEY_PASSWORD
• Key Properties: android/key.properties (generated by workflow)
• PKCS12 Store: android/app/seeruta-release.p12 (decoded from secret)

5. Build Procedure

Step 1 — Clone the repository:
    git clone https://github.com/FilipinoCollabEmtech/flutter-widget-catalog.git
    cd flutter-widget-catalog
    git checkout map_on_home

Step 2 — Install dependencies:
    D:\Programs\flutter\bin\flutter.bat pub get

Step 3 — Run static analysis:
    D:\Programs\flutter\bin\flutter.bat analyze
    (Expected: 0 errors; pre-existing info lints are acceptable)

Step 4 — Run the app (requires Android device/emulator):
    D:\Programs\flutter\bin\flutter.bat run

Step 5 — Build release APK:
    D:\Programs\flutter\bin\flutter.bat build apk --release

8. Asset Pipeline

The MBTiles file (assets/maps/cebu_city.mbtiles, 41.3 MB) contains OpenMapTiles vector data for Cebu City (zoom levels 0–14, TMS scheme, gzip-compressed PBF). Glyph folders under assets/glyphs/ provide NotoSans fonts for map labels. On first launch, OfflineMapAssets.prepare() copies these to app storage and writes a MapLibre-compatible style.json.

9. Deployment

Debug and release APKs are signed with the same fixed release key. If a user already installed an older build signed with an ephemeral debug key, they must uninstall it once before installing a release-signed build. Builds from the same keystore update normally.
